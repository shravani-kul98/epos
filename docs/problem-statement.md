# Problem Statement

## Context

Engineering and digital-transformation programmes generate project signals across many
disconnected systems: schedule tools, risk registers, requirements repositories, test
management, supplier trackers and spreadsheets. Each system holds a partial truth. No single
view answers the questions a PMO or engineering leadership team actually asks.

## The problem

Because project data is **fragmented**, management typically faces:

- **No consolidated portfolio view** — status is assembled manually from many exports.
- **Unexplained RAG status** — a project is "Amber", but the reason is buried in a slide.
- **Low trust in data** — status dates are stale, owners are blank, evidence is missing, yet
  the numbers are still reported as fact.
- **Weak traceability** — it is hard to prove that a requirement is implemented, tested and
  verified before a release gate.
- **Blind change impact** — when a requirement changes or a supplier slips, nobody can quickly
  see which tasks, tests, milestones and releases are affected.
- **Manual reporting** — executive updates are written by hand, slowly, and inconsistently.

## Why it matters

Fragmentation causes late surprises, unowned risks, missed verification and slow decisions.
The cost is schedule slippage, rework, and reduced confidence in engineering governance.

## What EPOS Lite does

EPOS Lite is a focused **project-intelligence and governance prototype**. It consolidates a
small set of **structured, validated signals** into one explainable management view and:

1. Calculates **deterministic** Health and Confidence scores with visible evidence.
2. Raises **rule-based** early-warning alerts.
3. Provides **requirements traceability** and **change-impact** analysis.
4. Simulates **what-if scenarios** (e.g. supplier delay) without mutating baseline data.
5. Uses **GPT-4o only to explain** validated facts into a human-reviewed executive draft.

## What EPOS Lite is not

EPOS Lite is **not** a replacement for Jira, Microsoft Planner, SAP, Visure, IBM DOORS,
Polarion or Power BI. It is an integration/intelligence layer that demonstrates how selected
signals from those systems could be consolidated into one trustworthy, explainable view.
